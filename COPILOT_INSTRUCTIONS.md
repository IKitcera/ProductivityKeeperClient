# GitHub Copilot Instructions

This file provides workspace-level instructions for GitHub Copilot and other AI coding assistants. You can add guidelines, preferences, or rules for code style, architecture, naming, or anything else you want Copilot to follow in this project.

## Example Instructions
- Use Angular best practices for all new components and services.
- Prefer SCSS for stylesheets and keep them minimal and maintainable.
- Use modern, accessible, and high-contrast UI patterns.
- Avoid inline styles and JavaScript-based DOM manipulation.
- Use RxJS for async flows and avoid callback hell.
- Use English for all code comments and documentation.

## Custom Project Rules
- Provide modern and sylish solutions
- All components must support both light and dark themes.
- Use Tailwind or Material classes for spacing and layout where possible.

Add or edit these instructions as your project evolves.
